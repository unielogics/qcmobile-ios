QualifiedCommercialMeetingsWidget.swift is the WidgetKit source for the iOS home-screen widget.

This Expo-managed repo does not currently check in an Xcode workspace/project. During iOS prebuild or Xcode setup, add this folder as a Widget Extension target, enable the `group.com.qualifiedcommercial.mobile` App Group on the app and widget targets, and include `../QCWidgetData/QCWidgetData.swift` plus `../QCWidgetData/QCWidgetDataBridge.m` in the main app target.
